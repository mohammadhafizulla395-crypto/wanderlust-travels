# Wanderlust Travels

A polished frontend-only travel agency showcase website built with React, Vite, and Tailwind CSS v4.

## Tech Stack

- **React 19** with React Router v7 (SPA, lazy-loaded routes)
- **Vite 8** for build tooling
- **Tailwind CSS v4** with custom design tokens
- **Framer Motion** for animations
- **Lucide-free SVG icons** throughout

## Features

- Homepage with hero, stats, tours, destinations, gallery, testimonials, CTA
- 14 routes including destination & tour details, blog, gallery, reviews, FAQ, contact, booking
- WhatsApp integration for enquiries (number: +91 91005 27275)
- Fully responsive (320px – 1440px+)
- Lazy-loaded routes with loading spinners
- SEO meta tags and OG tags

## Local Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

Output goes to `dist/`.

## Deployment

Deployed to **Vercel** as a static SPA. No backend required.
